# GRC Workbench

Releases and support for **GRC Workbench**, a desktop app for tracking
vulnerability remediation across scan cycles: it reads Nessus scans
(.nessus and CSV), compares each cycle with the last, tracks findings per
site, and produces tickets for Zendesk, Jira or ServiceNow, closure audit
records, the analyzer workbook and a Word report.

- Windows: GRC Workbench is available from the Microsoft Store (direct link).
- [Privacy policy](PRIVACY.md): the app collects nothing and works offline.
- Questions or problems: [open an issue](https://github.com/4realIA/grc-workbench-releases/issues).
  Please don't include scan files, host names, IP addresses or other client
  data in an issue: this repository is public.

GRC Workbench is an independent tool, not affiliated with or endorsed by
Tenable, Zendesk, Atlassian or ServiceNow.
